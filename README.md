RIFTBOUND: THE LAST PORTAL

A multiplayer fantasy puzzle adventure game!

About the Game

RIFTBOUND is an exciting real-time multiplayer game where 2–6 players work together to solve puzzles, explore a magical kingdom, and defeat the Shadow Dragon.

Features

- Real-time multiplayer gameplay
- Create and join rooms using room codes
- Five challenging puzzle levels
- 90-second countdown timer
- Team and individual scoring
- Hints and exciting challenges
- Final Shadow Dragon challenge

Goal

Solve every puzzle, defeat the Shadow Dragon, and unlock the Last Portal!

Team Up. Solve Puzzles. Defeat the Dragon. Save the Kingdom!
